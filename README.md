# 伊豆秋日手册

2026/11/24—28 东京与伊豆公共交通旅行计划。

静态 HTML/CSS/JavaScript，包含每日地图、优先级筛选、机场切换、本地勾选保存与全行程打印。

[在线手册](https://sara-chen111.github.io/izu-autumn-2026/)

所有时刻为目标规划窗口；出行前核验具体车次、营业、天气及预约。地图连线是顺序示意，不是实际道路。Google评分为查询日快照；Leaflet 1.9.4 地图组件遵循 BSD-2-Clause，底图归 OpenStreetMap contributors。照片由修善寺观光协会官网远程加载并署名，未复制到仓库。
